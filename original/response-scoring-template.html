✏️ Project Overview

In this project, you will first check if rendering repairs made to the task data is correct, check if the provided reference answer is correct, and then score two {{domain}} responses individually from 0 to 10 against the Reference Answer.

📎 Task Flow

  1. Validate that the rendering repair is correct.

  2. Read the prompt, responses, and Reference Answer in the task data section. These will populate once you validate that the rendering repair is correct.

  3. Check the accuracy of the Reference Answer.

  4. For each response, score it from 0 to 10 against the Reference Answer using the score bands, and explain the score.

❗️ Important Project Reminders

  • Formatting differences are not errors unless the prompt requires a specific format.

  • Responses should not be penalized for including the prefix "Answer:".

  • LaTeX, plain text, and Markdown are all acceptable, "Answer: 10" and "10" are the same answer, and 1/2 and 0.5 are equivalent.

  • Judge content, not appearance. The exception is when the question explicitly asks for a particular format, units, or level of precision, in which case you must enforce exactly what was asked.

  • A response disagreeing with the Reference Answer is not evidence that the Reference Answer is wrong. The Reference Answer will almost always be correct, and the more likely explanation is that the response is incorrect. Mark the Reference Answer incorrect only when you have worked out the correct answer yourself and are confident it is incorrect.

  • Score the final answer. Do not lower the score for missing steps or reasoning unless the prompt asks for them.

📍 Step by Step Instructions

⚙️ Step 0: Check the Rendering Repairs (do this first)

This is a sanity check for you to say whether automated formatting repairs changed the meaning of the responses or answer.

  • 0.1 On the right panel, locate the rendering checks for Response A, Response B, and the Reference Answer.

  • 0.2 Read the Repair Description. If it says "No repairs required", select "Yes" and move on.

  • 0.3 If a repair was made, compare the original and repaired text in the Repairs row. Select "Side by Side" to see them next to each other.

  • 0.4 If the repairs changed the meaning of the response in any way, select "No". Otherwise, select "Yes".

    • Adding $...$ around maths or closing a missing bracket is fine (select "Yes")

    • A changed number, sign, variable or final answer is not (select "No")

  • 0.5 If you select "No" for Response A, Response B, or the Reference Answer, you will be asked to provide a brief explanation of how the repair changed the meaning, and submit the task.

  • 0.6 If you selected "Yes" for all three, the Responses and Reference Answer will now appear in the Task Data section. Read the prompt, the Responses and the Reference Answer, then move on to Step 1.

🔧 Step 1: Reference Answer Check

Before proceeding to grading the responses, confirm whether the Reference Answer is correct.

  • 1.1 Mark the Reference Answer Correct or Incorrect. Only mark it Incorrect if you worked out the correct answer yourself and are confident the reference answer does not match it.

  • 1.2 If you marked it Incorrect, explain in 3 to 5 sentences. Your explanation must state the correct answer and say why it is correct.

⚒️ Steps 2 & 3: Grade Response A and Response B

Score each response on its own; ties are allowed. Look only at Response A in this step.

  • 2.1 Compare the response with the Reference Answer, decide which score band it falls in, then choose the score within that band.

  • 2.2 Give a 1 to 3 sentence rationale for that score, saying whether the final answer matches and naming any issue that lowered it. Match the level of detail you include to the complexity of the task.

📝 Grading Guidelines

You will score each response from 0 to 10. A response earns a 10 only when it meets every full-credit rule; the score bands cover everything else. Please read the rules below to make sure you submit a quality task.

📏 Full-credit rules

Compare each response with the provided reference answer to determine whether they represent the same answer while satisfying any explicit requirements in the prompt. Use the guidelines below to understand how "represent the same answer" is defined for this project:

Factor

Met Conditions (All must be met for a score of 10)

Not Met Conditions (Any one of these lowers the score; see the score bands)

Answer content

Met: The response gives the same answer as the reference and includes all required parts.

Not met: The response gives a different value or object, or leaves out a required part.

Formatting

Met: Any differences are harmless, such as “Answer: 10” vs. “10,” or “X = \frac{\pi^2}{3}” vs. “\frac{\pi^2}{3}”. LaTeX, plain text, and Markdown are all acceptable unless a specific format is required.

Not met: The response does not follow a format explicitly required by the question.

Equivalence

Met: The response is mathematically equivalent to the reference or can be simplified to it without adding assumptions, such as 1/2 vs. 0.5 or 2√2 vs. √8.

Not met: The response is not equivalent, or making it equivalent requires new assumptions.

Units

Met: The response includes the required units. If units are not required, answers with or without units are acceptable when the number matches.

Not met: The question requires units, and the response omits them or uses incorrect units.

Rounding

Met: The response meets any stated exactness or precision requirement. If neither is specified, a small rounding difference at the same intended precision is acceptable (e.g., 9.42 vs. 9.43).

Not met: The response fails the stated exactness or precision requirement, including giving a decimal approximation when an exact value is required, or differs by more than acceptable rounding.

📐 Score bands

First decide which band the response falls in, then choose the score within that band. Most responses here are bare final answers, so most scores will be 10 or 0. In-between scores mostly come from units, precision, exact form, and multi-part answers.

Rubric band

With bare final answers

10

Fully correct. The final answer is equivalent to the Reference Answer, the reasoning is valid, and all requested parts are addressed.

Use when: the response meets every full-credit rule. Missing steps or reasoning do not lower the score unless the prompt asks for them.

8–9

Minor issue. Correct overall with only a minor omission, notation issue, or harmless imprecision.

Use when: the answer is correct with one minor issue (9) or more than one (8).

5–7

Important issue. Substantial correct progress, but an important step, part, precision requirement, or justification is missing or flawed.

Use when: a requested unit, precision level, exact form, reasoning, or one required part is missing or wrong (7 for one issue, lower for more).

1–4

Limited progress. Limited relevant progress, with a materially incorrect result or method.

Use when: the final answer is wrong, but part of it is right, such as one part of a multi-part answer (more correct parts, higher score).

0

Incorrect. Incorrect, irrelevant, or does not answer the question.

Use when: the final answer is wrong, including numbers that are close but not equivalent.
